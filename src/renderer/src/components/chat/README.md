# Chat Components (`src/renderer/src/components/chat/`)

This directory contains the core conversational interface components, from the prompt composer to markdown rendering, code formatting, and attachment management.

---

## Files Overview

### 1. [`ChatArea.tsx`](file:///c:/Users/raghav/Desktop/spare/box/src/renderer/src/components/chat/ChatArea.tsx)
- **Role**: Primary Chat Viewport Controller.
- **Key Features**:
  - **Thread Header**: Displays active conversation title, active provider/model badge, parameter tuning popover (Temperature, Max Tokens, System Prompt), and export menu.
  - **Message Scroll Area**: Auto-scrolls to the newest message during generation with user scroll-intent detection.
  - **Welcome Screen Fallback**: Renders [`WelcomeScreen.tsx`](file:///c:/Users/raghav/Desktop/spare/box/src/renderer/src/components/chat/WelcomeScreen.tsx) when no messages exist in the conversation.
  - **Bottom Dock**: Pins [`MessageComposer.tsx`](file:///c:/Users/raghav/Desktop/spare/box/src/renderer/src/components/chat/MessageComposer.tsx) with a subtle upward gradient mask.

---

### 2. [`MessageComposer.tsx`](file:///c:/Users/raghav/Desktop/spare/box/src/renderer/src/components/chat/MessageComposer.tsx)
- **Role**: Elevated Card Message Composer.
- **Key Features**:
  - Auto-growing multi-line textarea (`Enter` to submit, `Shift + Enter` for newlines).
  - **Keyboard Shortcut Focus**: Listens for the `'focus-message-input'` event triggered by **`Ctrl + .`** or **`Cmd + .`** to immediately focus the composer and select text.
  - **Action Toolbar**:
    - File attachment button with native dialog invocation.
    - Quick model pill with active provider status.
    - Primary Send button (`ArrowUp`) or Stop Generation button (`Square`).
  - **Attachment Strip**: Displays pending attachment chips before dispatching.

---

### 3. [`MessageItem.tsx`](file:///c:/Users/raghav/Desktop/spare/box/src/renderer/src/components/chat/MessageItem.tsx)
- **Role**: Chat Bubble Component for user and assistant messages.
- **Key Features**:
  - Minimalist role avatars (User icon vs. Bot icon).
  - **Status Indicators**:
    - **"Thinking..." Pulse**: Sleek animated 3-dot pulse displayed during active generation before text arrives.
    - **Latency Badge**: Monospace execution duration (e.g. `1240ms`).
    - **Token Badge**: Total tokens consumed.
  - **Action Menu**: One-click Copy, Edit & Resend (user), Retry (assistant), and Delete.
  - **Error Alert Box**: High-contrast destructive alert for failed API requests with retry button.

---

### 4. [`MarkdownRenderer.tsx`](file:///c:/Users/raghav/Desktop/spare/box/src/renderer/src/components/chat/MarkdownRenderer.tsx)
- **Role**: Rich Content & Reasoning Renderer.
- **Key Features**:
  - **Thought Process Accordion**: Parses `<think>...</think>` tags generated by reasoning models (DeepSeek-R1 / Qwen) and renders an elegant, collapsible disclosure box with a disclosure chevron.
  - **GitHub Flavored Markdown**: Tables, task lists, blockquotes, and link interception to native browser via `window.electronAPI.openExternal`.
  - **LaTeX Math Formulas**: Integrated `rehype-katex` and `remark-math` rendering inline and block equations.

---

### 5. [`CodeBlock.tsx`](file:///c:/Users/raghav/Desktop/spare/box/src/renderer/src/components/chat/CodeBlock.tsx)
- **Role**: Code Snippet Container.
- **Key Features**:
  - Header with detected language badge (e.g. `typescript`, `python`).
  - Copy-to-clipboard button with checkmark confirmation feedback.
  - Geist Mono typography with horizontal scrolling.

---

### 6. [`WelcomeScreen.tsx`](file:///c:/Users/raghav/Desktop/spare/box/src/renderer/src/components/chat/WelcomeScreen.tsx)
- **Role**: Empty State / New Chat Landing View.
- **Key Features**:
  - Hero section with badge pill and Geist Sans display heading.
  - 2x2 Bento Grid of starter prompts (Code, Analysis, Writing, Ideas).
  - Clicking any card populates the composer textarea and focuses it.

---

### 7. [`AttachmentChip.tsx`](file:///c:/Users/raghav/Desktop/spare/box/src/renderer/src/components/chat/AttachmentChip.tsx) & [`AttachmentModal.tsx`](file:///c:/Users/raghav/Desktop/spare/box/src/renderer/src/components/chat/AttachmentModal.tsx)
- **AttachmentChip**: Compact pill showing file extension icon, truncated name, byte size, and remove button.
- **AttachmentModal**: Full modal viewer for inspecting extracted document text, token counts, or image previews.
